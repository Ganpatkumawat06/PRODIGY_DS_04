Prodigy InfoTech Task 4 - Sentiment Analysis
Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards specific topics or brands.

Dataset
Official Prodigy InfoTech Task 4 dataset: twitter_training.csv

The dataset contains social-media posts with an ID, entity/topic, sentiment label, and text.

Analysis Performed
Data cleaning and missing-value handling
Overall sentiment distribution
Entity/post-volume analysis
Sentiment distribution across top entities
Common-word frequency analysis
